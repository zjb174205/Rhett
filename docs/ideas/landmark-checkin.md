# 候选方向 B｜地标打卡与社区画布

**状态**：候选 / 调研准备；尚未确定立项、MVP、平台或技术栈。与大学生信息服务方向独立管理。

## 初步产品假设
在现实地点与地标对应的数字空间里，探索打卡、留言、故事、印记与涂鸦等互动形式，让地点成为可以持续承载社区内容的载体。

## 需要验证
- 用户为什么愿意到现场参与，离开后为什么再次打开？
- 以“签到”“故事”“涂鸦画布”哪种行为为核心，更有可验证的价值？
- 如何处理错误定位、虚假打卡、地点信息与空间数据的合规使用？
- 公共内容如何进行版权授权、审核、举报、撤回和反破坏？
- 冷启动时如何让某个地标的内容密度足够有用？

## 第一阶段最小产物
1. 选定一个供访谈使用的典型地标场景（并非上线范围承诺）。
2. 用户从发现地点、到场、留下内容到回看的流程草图。
3. 内容审核、位置权限及维护成本初步清单。

## 暂不决定
不预设地图提供商、商业模式、城市覆盖、语音能力或发布日期。先把非语音内容互动作为讨论起点，具体功能边界等待确认。

> 下一步：访谈潜在打卡用户并测试最小交互流程，避免将“有趣”直接等同于长期留存。
